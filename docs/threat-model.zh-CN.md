# Amagine3D 威胁模型

> **English**: [View the English version](./threat-model.md)

状态：发布基线，2026-08-15

## 安全边界

Amagine3D 将模型输出、生成的 Python、Web 搜索结果、导入的 ZIP 文件、恢复的项目数据、附件元数据、URL 和文件名都视为不受信任的数据。浏览器 CAD 执行在专用 Worker 中运行，不持有模型或搜索凭据。提供商凭据只存在于仅服务端使用的环境变量中，绝不会成为项目存储或导出压缩包的一部分。

## 威胁与控制

| 领域           | 主要威胁                                                    | 强制控制                                                                                                                                           | 残余风险 / 操作方行动                                                                            |
| -------------- | ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| AI 生成 Python | 文件/网络访问、动态代码逃逸、跨 skill helper 使用、拒绝服务 | 主机校验加 Python AST 校验、导入与内建对象白名单、finalizer/输出限制、隔离的 Worker、项目/run 目录、构建超时、Worker 终止、受限日志与产物          | WebAssembly 并非完整的敌对代码沙箱。不要让本地应用暴露给不受信任的远程用户；请私密上报策略绕过。 |
| Web 研究       | 提示注入、错误尺寸、SSRF 或超大/伪造参考图                  | 用户主动开启的研究闸门、无原始 HTML、受限结构化摘要、仅公共 HTTPS 图片主机、重定向复核、MIME/魔数与字节限制、用户约束优先、图片 soft-fail          | 来源仍可能出错。制造前请复核引用的机械图纸。                                                     |
| ZIP 导入       | 路径穿越、重复路径、畸形目录、超大压缩包                    | 仅 Stored ZIP32、拒绝绝对/反斜杠/盘符/`.`/`..`、拒绝重复项、CRC/校验和验证、条目数和 512 MiB 压缩包限制、在修改仓库前预检                          | 合法的大型压缩包可能占用大量内存。只导入预期的项目备份。                                         |
| XSS / Markdown | 可脚本化链接、HTML 注入、点击劫持                           | React 文本渲染、无 `dangerouslySetInnerHTML`、受限的 reasoning 渲染器、仅 HTTP(S) 外部链接、`noopener noreferrer`、CSP、禁止 frame、禁用 MIME 嗅探 | 静态 CSP 允许当前 Next.js 构建所需的内联样式/脚本。未来的 nonce 滚动可进一步收紧。               |
| 运行时 URL     | 远程运行时替换或碎片化依赖请求                              | 版本化同源运行时 bundle、固定 SHA-256、严格 bundle 索引、拒绝意外的运行时拉取、不可变缓存头                                                        | 首个 bundle 很大；用户应等待明确的就绪状态。                                                     |
| 下载           | 类路径或控制字符文件名滥用                                  | 产物 schema、存储段校验、浏览器下载前的安全叶文件名规范化                                                                                          | 操作系统仍可能改写文件名。在别处打开前请核实扩展名/内容。                                        |
| 附件           | MIME 欺骗、超大/解压过重的图片、密钥泄露                    | MIME 加魔数校验、数量/字节/像素限制、附件哈希、能力 gate、服务端重新校验                                                                           | 图片会发送给所选的提供商。除非提供商策略允许，否则不要附加机密材料。                             |
| 密钥           | 通过 UI、日志、Worker 或 ZIP 泄露密钥                       | 仅服务端环境访问、浏览器请求使用 profile ID、浏览器包中无提供商 SDK、项目 schema 中无密钥                                                          | 本地 `.env.local` 仍由操作方管理，不得提交。疑似泄露后请轮换密钥。                               |
